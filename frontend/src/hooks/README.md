# Hooks 目录约定

`hooks` 只放 Vue Composition API 形式的可复用状态和生命周期逻辑，不作为所有工具函数的集中目录。

## 分类

- `common/`：不依赖具体业务模块的状态逻辑，例如异步 loading、轮询定时器。
- `browser/`：浏览器资源和组件生命周期逻辑，例如 Blob URL 的创建与释放。
- `system/`：系统管理领域的可复用逻辑，例如字典选项加载。

## 当前 hook

| Hook | 用途 | 使用页面 |
| --- | --- | --- |
| `useAsyncLoading` | 统一异步操作的 loading 开关 | 监控在线用户、服务器、资源页 |
| `usePolling` | 创建、重启并自动清理轮询定时器 | 监控在线用户、服务器 |
| `useObjectUrl` | 管理文件预览 Blob URL，组件销毁时释放 | 个人资料页 |
| `useDictOptions` | 管理字典选项和加载状态 | 个人资料页、用户管理页 |

## 放置边界

- 纯函数、下载、格式化和请求封装继续放在 `utils` 或 `api`。
- 跨页面的全局状态继续放在 `store`。
- 只服务于单个页面的表单字段、统计计算和弹窗状态保留在页面组件内。
